# Datos de Prueba

Este directorio contiene fixtures, mocks y datos de prueba utilizados por las pruebas.

## Convences

- Nombra los archivos como `<modulo>-<tipo>.json` (ej: `usuarios-fixture.json`).
- No incluyas datos sensibles o reales en este directorio. Usa `data/sensitive/` (ignorado por git) para eso.
- Los mocks de APIs van en `data/mocks/`.
- Los fixtures de BD van en `data/fixtures/`.
